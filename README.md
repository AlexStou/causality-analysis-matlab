# Λογισμικό MATLAB για μέτρα αιτιότητας και δίκτυα αιτιότητας σε πολυμεταβλητές χρονοσειρές

Κώδικας της διπλωματικής εργασίας *«Ανάπτυξη λογισμικού για τον υπολογισμό μέτρων αιτιότητας κατά Granger σε πολυμεταβλητές χρονοσειρές και σχηματισμός δικτύων αιτιότητας»*, Τμήμα Ηλεκτρολόγων Μηχανικών και Μηχανικών Υπολογιστών, Αριστοτέλειο Πανεπιστήμιο Θεσσαλονίκης.

Το λογισμικό υπολογίζει έξι μέτρα συσχέτισης και αιτιότητας μέσω γραφικής διεπαφής:
Διασυσχέτιση (CC), Αμοιβαία Πληροφορία (MI), Δείκτη Αιτιότητας κατά Granger (GCI), Δείκτη Δεσμευμένης Αιτιότητας κατά Granger (CGCI), Εντροπία Μεταφοράς (TE) και Μερική Εντροπία Μεταφοράς (PTE). Τα αποτελέσματα εμφανίζονται ως πίνακες, θερμικοί χάρτες και γραφήματα δικτύου.

## Απαιτήσεις

- MATLAB (δοκιμάστηκε στην έκδοση R2023b)
- Statistics and Machine Learning Toolbox (συναρτήσεις `knnsearch`, `rangesearch`, `fcdf`, `tcdf`)

## Γρήγορη εκκίνηση

**Γραφική διεπαφή**
```matlab
cd src
app1
```
Load time series → επιλογή αρχείου από τον φάκελο `data` → Select/run measures → View measures / Show matrices.

**Επίδειξη χωρίς γραφική διεπαφή** (υπολογίζει και τα έξι μέτρα, τυπώνει τους πίνακες, τις σημαντικές σχέσεις με και χωρίς διόρθωση FDR, και σχεδιάζει θερμικούς χάρτες)
```matlab
cd demo
run_demo                              % συνθετικό μηχανολογικό σύστημα
run_demo('oikonomika')                % συνθετικό οικονομικό σύστημα
run_demo('pragmatika_mixanologika')   % πραγματικά δεδομένα κατοικίας
run_demo('pragmatika_oikonomika')     % πραγματικοί οικονομικοί δείκτες
```
Για τα συνθετικά συστήματα, το demo συγκρίνει τις σχέσεις που εντοπίζει ο CGCI με τη γνωστή δομή αιτιότητας.

**Χρόνοι εκτέλεσης** (Ενότητα 5.7 της εργασίας)
```matlab
cd demo
measure_times
```

## Δομή του αποθετηρίου

```
src/                 Κώδικας του λογισμικού
  app1.m             Κύρια εφαρμογή (φόρτωση δεδομένων, αποτελέσματα, γραφήματα)
  secondApp.m        Επιλογή και υπολογισμός μέτρων
  *App.m             Παράθυρα παραμέτρων των μέτρων
  GCinAll.m, CGCinall.m, TEnneiAll.m, PTEnneiAll.m   Υπολογιστικός πυρήνας
  annMaxquery.m, annMaxRvaryquery.m, nneighforgivenr.m, rangescale.m   Βοηθητικές συναρτήσεις
data/synthetic/      Συνθετικά δεδομένα με γνωστή δομή και οι συναρτήσεις παραγωγής τους
data/real/           Πραγματικά δεδομένα (μετασχηματισμένα, έτοιμα για το λογισμικό)
demo/                run_demo.m, measure_times.m
```

## Μορφή δεδομένων εισόδου

Αρχείο κειμένου (.txt) με πίνακα N × K (μία στήλη ανά χρονοσειρά). Προαιρετικά: πρώτη γραμμή με ονόματα μεταβλητών και πρώτη στήλη χρόνου. Διαχωριστικά: tab, κενό, κόμμα ή ερωτηματικό. Αρχεία με ελλείπουσες ή μη-πεπερασμένες τιμές (NaN, Inf) απορρίπτονται με μήνυμα που δείχνει τις θέσεις τους.

## Δεδομένα

| Αρχείο | Περιγραφή | N × K |
|---|---|---|
| `synthetic/oikonomika.txt` | Συνθετικό οικονομικό σύστημα (Oil, Rate, Invest, GDP, Stock) | 1000 × 5 |
| `synthetic/mixanikou.txt` | Συνθετικό σύστημα άντλησης (Pump, Flow, Press, Temp1, Temp2, Vib) | 5000 × 6 |
| `real/pragmatika_mixanologika.txt` | Ωριαίοι μέσοι όροι από το UCI *Appliances Energy Prediction* (Candanedo et al., 2017), μεταβολές θερμοκρασιών/υγρασίας | 3289 × 6 |
| `real/pragmatika_oikonomika.txt` | Μηνιαίες μεταβολές WTI (U.S. EIA), CPI, 10ετούς επιτοκίου και S&P 500 (R. Shiller), 02/1986–06/2023 | 449 × 4 |

Οι εξισώσεις των συνθετικών συστημάτων και οι μετασχηματισμοί των πραγματικών δεδομένων περιγράφονται στο Κεφάλαιο 5 της εργασίας.

## Ευχαριστίες και πνευματικά δικαιώματα

Οι συναρτήσεις του υπολογιστικού πυρήνα (`GCinAll`, `CGCinall`, `TEnneiAll`, `PTEnneiAll` και οι βοηθητικές συναρτήσεις αναζήτησης γειτόνων) παραχωρήθηκαν από τον επιβλέποντα καθηγητή Δ. Κουγιουμτζή. Τα πραγματικά δεδομένα ανήκουν στις αντίστοιχες πηγές τους.
